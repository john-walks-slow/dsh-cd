## e2e 行为验证（2026-09-27，通过）

环境：e2e 实例（独立 DSH_HOME，link 安装 dsh-cd），GUI 发消息驱动真实模型一轮对话，指令其依次执行 5 个工具调用。结果（会话日志 `session-5221d978-daed-403f-a2d3-600b32a55f03`，cwd=~/projects/virtual-connect）：

| # | 调用（模型原始参数） | 结果 |
|---|---|---|
| 1 | `cd {"path":"/tmp/dsh-cd-e2e"}` | `{"cwd":"/tmp/dsh-cd-e2e","override":true,"previous":"~/projects/virtual-connect","sessionWorkspaceRoot":"~/projects/virtual-connect"}` |
| 2 | `write {"file_path":"hello.txt","content":"ok"}` | 文件创建于 `/tmp/dsh-cd-e2e/hello.txt`（相对路径被改写到覆盖目录） |
| 3 | `bash {"command":"pwd"}`（无 workdir） | 输出 `/tmp/dsh-cd-e2e`（默认 workdir 跟随覆盖） |
| 4 | `read {"file_path":"hello.txt"}` | 读到 `/tmp/dsh-cd-e2e/hello.txt`，内容 `ok` |
| 5 | `cd {}`（查询） | `{"cwd":"/tmp/dsh-cd-e2e","override":true,...}` |

- 会话工作区根 `~/projects/virtual-connect` 下**未**产生 `hello.txt`（无污染）
- `state.json` 含该会话条目（cwd、previous、updatedAt）
