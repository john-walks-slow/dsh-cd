# 260927-cd-tool 总结

**需求**：dsh 无会话内切换工作目录的工具；需要"cd 之后文件操作相对目录、bash cwd 都跟随"的原地切换。

## 方案（关键决策）

调研结论（详见 research.md）：dsh 的 `session.header.cwd` 是会话身份（创建时冻结、派生磁盘存储路径、ApiSessionCwdConflict 守卫、pre-execute waterfall 明确不改写参数），任何直接改它的方案都会破坏存储一致性（Claude Code #26875 同类事故）；fork 搬迁会话不满足"原地生效"。

**选定：agent 作用域工具影子**。全局注册 `cd` 工具管理按会话的覆盖状态；每个 agent 创建时在自己的 tools 作用域注册 bash/pwsh/read/write/edit/read_image/glob/grep/present 的影子（先取 original 再注册，execute 内仅改写路径类参数，无覆盖时原样透传）。会话身份、沙箱根、AGENTS.md/skills/MCP 发现根全部不动。

配套：cache 安全的系统提示快照（仅覆盖激活时注入）；state.json 原子持久化（30 天剪除）；子代理创建时快照父会话覆盖。
