# dsh-cd 调研结论（2026-09-27）

## 需求

dsh 会话内更改工作目录的工具：更改后**文件工具的相对路径解析基准**与 **bash 默认 workdir** 都跟随变化。

## dsh 现状（0.1.5-rc.3 源码结论）

- **没有 cd 工具。** `session.header.cwd` 是唯一真相源，所有下游在调用时读取它：
  - `dsh-tool-fs` `sessionCwd()` → read/write/edit 相对路径基准
  - `dsh-tool-fs-search` → glob/grep workdir
  - `dsh-tool-bash` → bash 默认 workdir
  - `dsh-agent-loop` `systemPrompt.variable("cwd")` → 系统提示词 `{{cwd}}`
  - `dsh-sandbox-policy` → workspace-write 沙箱根
  - `dsh-skill` / `dsh-agent-instructions` → skill 与 AGENTS.md 发现根
- **cwd 是会话身份，设计上不可变：**
  - header 对象创建时深冻结（`snapshotSessionHeader` → `validateSessionHeader` + freeze）
  - 存储路径由 cwd 派生（`projectDir(root, meta.cwd)`），磁盘 header 不可追加改写
  - `ApiSessionCwdConflict` 守卫 API 侧 cwd 一致性
  - `tools/pre-execute` waterfall 明确排除参数改写（"Input rewriting is excluded"）
- bash 工具有 per-call `workdir` 参数；文件工具无 cwd 参数。

## 生态同类方案

| 产品 | 方案 | 语义 |
|---|---|---|
| Claude Code | `/cd` 命令（v2.1.169+，**仅用户可调用**，`Cd` 权限规则） | **搬迁会话**：存储迁到新目录项目区、prompt cache 保留（新 CLAUDE.md 以消息追加）、`--resume` 从新目录找到它 |
| Claude Code | bash cwd 跨调用持久 | 只影响 bash，文件工具仍锚定原根（#37659 抱怨两者不一致） |
| opencode | v1.16.0 PR #30640 move-session 服务 | 会话在项目目录间搬迁（控制面操作） |
| Codex | shell per-call cwd；spawn_agent cwd 为 open feature (#18969) | 无 mid-session cd |
| 教训 | Claude Code #26875 | mid-session 改 projectPath 导致 storage/index 错位、会话不可达——**内存身份与磁盘身份分叉是真实事故源** |

市场（dshmarket 663 条目、npm）无同类 dsh 插件；上游 deepseek-harness 无相关 issue。

## 方案对比

1. **内存换 header.cwd**：一个改动点全部生效（含沙箱/技能/指令），但 `dsh-message-feedback` 对 live session 断言 `live.header.cwd === 存盘 header.cwd` → cd 后消息评分直接报错；且 GUI 工作区分组错位。**否决**。
2. **fs seam 装饰**：`ctx.fs` 层拿不到会话身份（只有 cwd 字符串），多会话无法区分。**否决**。
3. **会话搬迁**（Claude Code/opencode 语义）：fork 到新 cwd + 客户端切换视图。最 canonical，但只能按轮次生效、当前轮仍在旧会话、UX 割裂，且 dsh fork RPC 不接受 cwd 覆盖（需插件直调 `ctx.agents.create` + 客户端配合）。**不满足"原地生效"需求**。
4. **agent 作用域工具影子**（选定）：注册 `cd` 工具 + 在每个 agent 的自有层注册同名影子工具（registry 文档化行为："Scoped tools shadow globals"），只改写路径类参数：
   - bash/pwsh：缺省注入 `workdir`，相对 workdir 预解析
   - read/write/edit/read_image：相对 `file_path` 预解析
   - glob/grep：缺省注入 `path`，相对 `path` 预解析
   - present：`files[].path` 预解析
   - 运行时上下文快照（`systemPrompt.context`，cache-safe）向模型宣告当前覆盖目录
   - 不触碰会话身份/磁盘/沙箱根 → 沙箱策略、AGENTS.md、skills 仍锚定会话工作区（与 Claude Code `Cd` 权限规则同构的安全姿态）
   - 状态按 session id 持久化（`$DSH_HOME/dsh-cd/state.json`），重启后 agent/created 时恢复
