# dsh-cd 实施计划（2026-09-27）

## 形态

host-only cordis 插件（无 client bundle），TypeScript + tsc 构建。项目 `~/projects/dsh-cd`，包名 `dsh-cd`。

## 组件

1. **`cd` 工具**（全局注册，`ctx.tools.register`）
   - 参数：`path?`（绝对 / 相对 / `~` / `-` / 省略=查询）
   - 语义：解析目标（基于当前虚拟 cwd ?? session.header.cwd）→ realpath → 必须为存在目录；目标==会话工作区根时清除覆盖；否则记录 `{cwd, previous, updatedAt}`
   - 错误：throw（registry 归一化为失败结果）
2. **工具影子**（每个 `agent/created` + 启动时 `agents.roots()` 扫描，注册于 `agent.ctx` 自有层，`agentCtx.effect` 托管清理）
   - 影子对象 = `{...original, execute}`，仅改写路径类参数，透传 exec
   - 清单：bash、pwsh（如存在）、read、write、edit、read_image、glob、grep、present
   - 无覆盖或非本会话调用时原样透传
3. **运行时上下文**（agent 作用域 `systemPrompt.context`，order 112）
   - 仅在覆盖激活时输出一行：当前目录 + 适用工具 + 不变项（沙箱/指令/技能锚定）
4. **状态持久化**（`$DSH_HOME/dsh-cd/state.json`，tmp+rename 原子写）
   - 按 session id 存 `{cwd, previous?, updatedAt}`；保存时剪除 >30 天条目
   - agent/created 恢复（目录仍存在才恢复，否则丢弃）
   - 子代理（header.parentSession）创建时继承父会话当前覆盖（仅内存，不持久化继承值）

## 不做什么

- 不改 session.header / 磁盘 / 沙箱根 / 存储路径
- 不搬会话、不动 prompt cache（上下文快照走 history 通道）
- 不包装 MCP 工具（上下文提示模型用绝对路径）

## 验证

e2e 实例（DSH_HOME=/root/.dsh-e2e:4188）：cd 到临时目录 → 相对路径 write/read/glob 命中新目录 → bash 无 workdir 时 pwd 输出新目录 → 查询/`-`/非法路径分支 → 重启后覆盖恢复 → 回到工作区根后行为与原生一致。
